# ai-prompt-evaluator 🤖

> Systematic testing framework for evaluating LLM system prompts against cost, token length, and latency.

## Features
- Multi-model prompt variation testing.
- Automated cost estimation for OpenAI & Claude endpoints.
- Markdown leaderboard generation.
